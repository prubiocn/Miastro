# Fase 6 — UI natal mínima

La ficha de Persona incorpora una sección funcional de carta natal.

Incluye:

- detección de carta natal vigente;
- selección Placidus/Koch;
- acción «Calcular carta natal»;
- estado del cálculo;
- fecha de cálculo;
- sistema de casas;
- tabla básica de las 21 posiciones canónicas.

El cálculo sólo se habilita sobre una Persona persistida y sin cambios
pendientes de guardar.

La UI no expone detalles técnicos del motor, hashes, ABI, rutas ni versiones
internas.

Esta vista no es el diseño definitivo de carta natal y no contiene rueda
gráfica. La rueda pertenece a una fase posterior.
