# ADR-023 — CalculationProfile V1

## Estado

Aceptado.

## Decisión

El perfil canónico V1 fija:

- tropical;
- geocéntrico;
- longitud eclíptica;
- aparente;
- velocidad incluida;
- sin topocentrismo;
- Nodo Verdadero;
- Lilith Media.

## Consecuencia

Las decisiones de cálculo quedan explícitas antes de integrar Swiss Ephemeris.
