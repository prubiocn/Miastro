# ADR-022 — Regencias tradicionales y modernas

## Estado

Aceptado.

## Decisión

Miastro conserva por separado regencia tradicional y moderna.

Escorpio:
- tradicional: Marte
- moderna: Plutón

Acuario:
- tradicional: Saturno
- moderna: Urano

Piscis:
- tradicional: Júpiter
- moderna: Neptuno

No se incorpora capa esotérica en V1.
